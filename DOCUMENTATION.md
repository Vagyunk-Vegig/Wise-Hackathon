
# Documentation

## Tasks

- Date type: one-time task or habit (recouring task)
- Date if one-time:  its simlply one date
- Date if habit: can be set to daily, weekly, monthly, (yearly) and you can select in a week when you want it in a simple calendar widget
- Title: every tasks needs a title
- Description: can be added not necesarry
- Activity type: can be added to  a specific task group like: study, higene, fitness or (auto detect the type)
- Proof: can be added to show you did it, when you make it you can require it

## Task completion reward

- Main reward is XP.
- Every a flat xp value depending on their task type
- You can earn streaks by not missing task
- Streaks can give you special badges for earning milestones

## Task non-completion penalty

- Penalties can be disabled if wanted
- Non completing tasks has a set flat money penalty
- The penalty can be sent to a charity or to another bank account or somewhere else


## Leaderboard competition and profile

- Your profile contains your user info like name and age
- Your xp level is displayed
- A leetcode like activity calendar
- Your badges are displayed (longest streak is also a badge)
